Database Entities Reference

Table Name Description & Purpose Key Columns
app_user Stores core application users, authentication credentials, and permissions. id, username, email, role, kyc_status
trading_account Financial trading accounts. Holds balance, equity, leverage, credit line info, and lifetime commission paid. id, app_user_id, balance, equity, margin_used, commission_paid_total
broker_order Orders placed by accounts (MARKET, LIMIT, STOP). Stores execution prices and order commission. id, trading_account_id, symbol_code, side, status, commission
position Currently open active trading positions. Calculated live against market feeds. id, trading_account_id, symbol_code, side, quantity, avg_price, unrealized_pnl
account_transaction Financial ledger for deposits, withdrawals, and deducted trading commissions (COMMISSION). id, trading_account_id, tx_type, amount, status, created_at
margin_loan_ledger Logs borrowing, repayments, and daily interest charged on credit line usage. id, trading_account_id, entry_type, amount, rate_applied
trade_fill Detailed execution fills matching orders to market execution venues or AI liquidity engine. id, broker_order_id, fill_price, fill_quantity, external_order_id
user_preference Persisted user configuration settings (dark mode, language, AI recommendations). id, app_user_id, theme, language, ai_advisor_enabled
notification System notifications pushed to user (margin calls, trade executions, KYC updates). id, app_user_id, notif_type, title, body, is_read
kyc_case Compliance documentation and verification workflow state. id, app_user_id, full_name, document_url, status
audit_log Security audit trail capturing administrative and critical actions. id, app_user_id, action, details, ip_address
symbol Master instrument catalog (EURUSD, BTCUSD, AAPL) with contract sizing specifications. id, code, description, asset_class, contract_size
sim_trade Internal simulation trades used for evaluating AI Advisor prediction models. id, symbol_code, side, fill_price, realized_pnl
